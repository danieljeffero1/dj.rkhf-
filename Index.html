How Publishing Works

  1. Create your website using the form above.
  2. Preview and download your HTML file.
  3. Upload the file to a GitHub repository.
  4. Enable GitHub Pages in repository Settings.

GitHub Pages can host supported static websites for free.

This version generates downloadable websites. Automatic publishing directly from this app is not configured yet.
